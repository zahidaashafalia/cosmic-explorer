# Cosmic Explorer

Buat website edukasi interaktif Tata Surya dengan desain profesional, futuristik, immersive, dan modern.

Tampilkan Matahari di tengah dengan 8 planet mengorbit sesuai urutan: Merkurius, Venus, Bumi, Mars, Jupiter, Saturnus, Uranus, Neptunus. Setiap planet bergerak mengelilingi Matahari dengan kecepatan orbit berbeda dan animasi yang smooth.

Gunakan tema dark space dengan warna navy, hitam, ungu, blue/purple glow, bintang, dan efek nebula halus. Gunakan glassmorphism/transparansi untuk panel informasi.

Setiap planet dapat diklik. Saat diklik, planet menjadi fokus dengan efek zoom/glow, lalu muncul kotak informasi transparan berisi nama planet, urutan, jarak dari Matahari, diameter, rotasi, revolusi, satelit, atmosfer, dan fakta menarik.

Berikan transisi yang smooth, hover effect, tombol pause/resume/reset, serta tombol kembali ke tampilan seluruh tata surya.

Buat responsive untuk desktop, tablet, dan mobile. Gunakan React + CSS animation atau Three.js/React Three Fiber jika diperlukan.

Prioritaskan animasi orbit yang realistis, interaksi planet, glassmorphism, dan visual premium seperti digital planetarium. untuk referensi ada digambar jadi untuk dashboard atasnya itu gambarnya bumi
